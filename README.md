**LIBRERIA UTILIZADA**: SFML (Exactamente la version 3.1.0)

**COMO COMPILAR?:**

Ya teniendo el proyecto en mano, solamente presiona "f5" y este compilara.

**COMO EJECUTAR EL PROGRAMA?**

Tras iniciar, presiona "ENTER" para empezar.

Pero antes de eso selecciona el tipo ordenamiento para la puntuacion, esto mediante la tecla TAB en el menu del juego.

Teclas:

<- / ->  = Mover la pieza de izquierda a derecha

↓ = Presionarlo aumenta la velocidad de caida de la pieza.

↑ = Rota la pieza en las 4 posiciones disponibles(Arriba, Izquierda, Abajo, Derecha)

C : Guarda una pieza a la vez en la bolsa.

P : Pausar Juego

U : Deshacer Movimiento

R : Rehacer Movimiento

ESC : Salir del juego.


Tras finalizar la partida:

"F5" : Para ver tu ultima partida,

<- / -> : Retroceder y Avanzar durante el replay de tu ultima partida
